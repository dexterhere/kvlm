# Support

This is an early community project without a stable release or support SLA.

- For setup, begin with [getting started](docs/03-development/getting-started.md).
- For intended behavior, read the [documentation index](docs/README.md).
- For feature status, use the [roadmap](docs/04-roadmap/milestones.md) and [changelog](CHANGELOG.md).
- Use the [issue tracker](https://github.com/dexterhere/kvlm/issues) for reproducible
  bugs and the discussion facility, if maintainers enable it, for questions and ideas.
- For security concerns, follow [SECURITY.md](SECURITY.md); do not disclose them publicly.

A useful bug report includes the commit ID, Linux distribution, Rust/GTK/Libadwaita
versions, reproduction steps, expected behavior, and reviewed logs. Include GPU and
runtime versions when relevant. Remove access tokens and private machine details.

The configured repository is [dexterhere/kvlm](https://github.com/dexterhere/kvlm).
Private security reporting and a private conduct contact remain publication
prerequisites. There are no official chat rooms or support addresses yet.
