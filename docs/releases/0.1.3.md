## Kvlm 0.1.3 (beta pre-release)

Kvlm helps you run AI models on your own computer: it shows whether a model will fit your memory, what your
runtimes are doing, and how fast they really are. Nothing leaves your computer unless you press a button. This is a
beta, built mostly on one machine.

### A calmer interface

- **My computer** is the first page. It gives a plain summary of your processor, memory and graphics memory, with a
  rough starting model size. The memory calculator is still there, collapsed.
- **Runtimes** shows one runtime at a time: Ollama, llama.cpp, or LM Studio and vLLM.
- **Speed test** and **Experiments** keep options and past results in collapsed sections.
- The **llama.cpp** page now explains what it is, what Kvlm controls (only its own copy) and what it never touches
  (your Ollama, LM Studio and vLLM).
- **Preferences** (Ctrl+,): follow the system, light or dark.
- A **setup guide** opens on first run, one card at a time, with a hardware summary. Reopen it from the menu.
- **Hugging Face token**: a four-step "How to get a token" guide with a button that opens the token page when you
  press it.

### Install

- `scripts/install.sh` builds Kvlm and installs it under `~/.local`. It never uses sudo and has `--uninstall`.
- This tag's release workflow attaches a **Flatpak** and an **AppImage**, with SHA-256 checksums, once it has run.
  Both built in CI, but neither has been installed and run on a real machine yet. If they are not attached, build from
  source.

### Changed

- The application ID is now `io.github.dexterhere.Kvlm`. If you saved a Hugging Face token before, save it again.
- Security and conduct contacts are published. Use GitHub's private vulnerability reporting (Security tab) or
  buggybuckai@gmail.com.

### Measured on one machine

RTX 4050 Laptop (6 GiB), Qwen2.5-1.5B, same 16-bit weights, 160 tokens, median of 5:

| Runtime | Decode |
| --- | ---: |
| vLLM | 55.2 tok/s |
| Ollama | 53.2 tok/s |
| llama.cpp | 53.1 tok/s |
| LM Studio | 51.1 tok/s |

These differ by under 10%, which one run on one day cannot rank. The llama.cpp row used a CUDA build that came with LM
Studio, not Kvlm's own install. Full method, other results and caveats are in
`docs/03-development/runtime-benchmarks.md`.
